ЗАПУСК

Клонируйте.
Настройте один YAML.

# быстрый старт
git clone https://github.com/zarazhangrui/po-agent-suite.git
cd po-agent-suite
cp .env.example .env
docker compose up -d
# откройте http://localhost:3000

provider: openai model: gpt-4o
data_sources: jira · github · csv · db
style: corporate · ru · your logo
