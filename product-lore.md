# PO Agent Suite — product lore

PO Agent Suite — универсальный open-source AI-инструмент для Product Owner и руководителя команды. Он работает из коробки и превращает естественный запрос в связанный комплект Data, Narrative и Slides.

## Для кого и зачем

Suite помогает Product Owner, Tech Lead, руководителю команды, Agile Coach, Scrum Master и небольшим командам. Его рабочие боли: ручной отчёт по Jira, презентация квартала, непонятный legacy-код и хаотичные требования заказчика.

## Продуктовый конвейер

Пользователь говорит с чат-интерфейсом. LLM-агент отделяет цель, факт, риск и неизвестность, планировщик выбирает инструменты, а результат появляется в трёх формах: таблица с доказательствами, сильный текст для коммуникации и браузерная презентация. Продуктовая схема: DataFetcher → TableGenerator → TextGenerator → SlideGenerator → CourseGenerator.

## Источники и модули

В замысле поддерживаются Jira, Trello, GitHub/GitLab, Google Analytics, CRM, базы данных, CSV и Excel. `codebase-to-course` превращает кодовую базу в интерактивный курс с переводом code ↔ plain English, потоками данных, архитектурными объяснениями и проверками. `frontend-slides` отвечает за красивые HTML-слайды, визуальные доказательства, графики, схемы и корпоративные стили.

## Принципы

Каждый вывод должен иметь источник. Факты, интерпретации, гипотезы и неизвестности разделяются. Нельзя выдавать fixture-числа за production-метрики. Indexator — отдельный продукт и не входит в Suite. Локальная модель через Ollama/Llama.cpp сохраняет приватность; удалённые модели могут подключаться через конфигурацию.

## Примеры живых запросов

- «Покажи статистику по спринту: закрытые задачи, баги, нагрузка и риск».
- «Сделай из прогресса квартала рассказ для стейкхолдеров».
- «Создай мини-курс по модулю авторизации для нового разработчика».
- «Преврати письмо заказчика про экспорт PDF в user story и критерии приёмки».
