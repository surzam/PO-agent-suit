# PO Agent Suite

Read `AGENTS.md` and the three PO worldview files before working. Treat the separate `Indexator` product as the source of backlog context; do not implement backlog prioritization here.

For each request:

1. inspect attached context files;
2. state the single product thesis;
3. identify supporting facts and unknowns;
4. generate the requested artifact;
5. for slides, create a browser-previewable HTML deck and a compatible Marp Markdown source;
6. run the quality checklist from `skills/quality.md`.
