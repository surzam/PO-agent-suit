# Язык по дороге домой

Это вымышленный учебный набор, не результаты реального продукта.
Приложение помогает взрослым учить язык после работы. Сейчас урок занимает примерно двадцать минут. Команда обсуждает пятиминутные занятия, но ещё не проводила эксперимент с длиной урока.
За одну неделю начато 100 первых уроков и завершено 60. Через неделю 28 из этих 100 пользователей начали ещё один урок. Причины ухода по этим числам неизвестны.
Нужно выбрать, что проверить первым: короткие уроки или более удобные напоминания. Короткий урок может быть удобнее, но его влияние на запоминание пока не измерялось.
