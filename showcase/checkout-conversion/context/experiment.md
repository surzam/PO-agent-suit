# Checkout experiment · демонстрационные данные

Новый mobile checkout показывался 52 400 сессиям, контроль — 51 870. Завершение покупки снизилось с 63,1% до 59,4%. На desktop статистически заметного изменения не было. Самый большой провал возник между выбором доставки и подтверждением адреса.

Эксперимент остановлен. Команда выбирает между полным rollback и исправлением адресного шага с повторным тестом.
