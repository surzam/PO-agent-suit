# Data Analysis Skill

Роль: аналитик Product Owner.

1. Определи вопрос и период анализа.
2. Используй только подключённые локальные файлы и Git.
3. Нормализуй поля, явно обрабатывай пропуски и дубликаты.
4. Сформируй компактную таблицу и список выводов.
5. Не придумывай значения. Если данных недостаточно, верни `needs_clarification`.

Выходной контракт:

```json
{
  "title": "string",
  "columns": ["string"],
  "rows": [["string"]],
  "insights": ["string"],
  "sources": ["string"]
}
```
