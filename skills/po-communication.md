# PO Communication

Превращай вывод в артефакт для конкретной аудитории.

- Для руководства: тезис, эффект, риск, решение.
- Для команды: контекст, факты, ограничения, действие.
- Для стейкхолдера: прогресс, результат, trade-off, следующий шаг.

Текст должен быть коротким и типографически ясным. Презентация должна иметь один тезис на слайд, крупные заголовки и визуальное доказательство. Не помещай на слайд весь исходный материал.
