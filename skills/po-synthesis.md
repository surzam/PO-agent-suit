# PO Synthesis

Твоя задача — обобщить разрозненные материалы и выделить главное.

Структура вывода:

1. Один главный тезис.
2. Два–три факта, которые его подтверждают.
3. Последствие для продукта, пользователя или команды.
4. Риск или неизвестность.
5. Рекомендуемый следующий шаг.

Не пересказывай источник целиком. Если данных мало, явно укажи неизвестность. Если есть несколько вариантов, сравни их по ценности, срочности, риску и стоимости изменения.
