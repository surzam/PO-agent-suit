# Slides Skill

Роль: редактор презентации.

Построй цепочку слайдов вокруг одного тезиса на слайд. Используй narrative и анализ как источники. Слайды должны быть пригодны для чтения на экране 1920×1080, без переполнений и мелкого текста.

Основной web-renderer: `frontend-slides`. Совместимый Markdown-источник: Marp. Marp ecosystem состоит из Marpit, Marp Core и Marp CLI; CLI используется для PDF/PPTX export, когда установлен отдельно.
